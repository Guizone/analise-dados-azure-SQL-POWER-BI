# Dados

Os arquivos de dados não ficam neste repositório.

## Como obter

1. Abra a página do dataset: https://archive.ics.uci.edu/dataset/222/bank+marketing
2. Baixe o arquivo zip.
3. Extraia o zip. O arquivo contém outro zip. Extraia também.
4. Use o arquivo `bank-additional-full.csv` (41.188 linhas, 20 variáveis de entrada e a variável alvo `y`).
5. Coloque o arquivo nesta pasta. O `.gitignore` impede o envio dele ao GitHub.
